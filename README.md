## PROBLEM STATEMENT
### Problem Description
Job seekers face difficulty efficiently identifying job opportunities that align with their skills, experience, and personal preferences due to the overwhelming volume of postings distributed across multiple platforms. Manually searching, filtering, and comparing listings is time-consuming and inefficient, often leading to missed opportunities or applications to poorly matched roles. This fragmented process reduces the overall effectiveness of the job search and increases frustration for candidates.

### Background
The modern job market is highly competitive and fragmented, with thousands of new job postings published daily across a wide range of platforms, including job boards, company career pages, and professional networking sites. While this abundance of opportunities should benefit job seekers, it instead creates information overload that makes effective job searching increasingly difficult.

### Impact
The lack of an efficient, centralized, and intelligent job-matching solution leads to wasted time, reduced productivity, and suboptimal hiring outcomes. Job seekers spend excessive effort navigating disparate platforms, while employers receive applications that may not meet their needs, slowing down the recruitment process.

### Need for a Solution
There is a clear need for an automated, intelligent system that streamlines job discovery by aggregating postings from multiple sources and filtering them based on personalized user criteria. Such a solution would reduce search complexity, improve match quality, and enable job seekers to focus their efforts on opportunities that best fit their qualifications and expectations.

## HOW TO USE & INSTALLATION INSTRUCTIONS
### Part 1: Initial Setup
Follow these steps to install and prepare CareerSphere on your computer.

#### 1. Install Required Software
Before downloading the project, make sure you have the following installed:
##### Python
- Go to: https://www.python.org/downloads
- Download the latest stable version.
- During installation:
  - Check “Add Python to PATH”
  - Click Install Now
##### Git
- Go to: https://git-scm.com/downloads
- Download and install Git using default settings.

#### 2. Clone the CareerSphere Repository
Open a terminal (Command Prompt, PowerShell, or macOS/Linux Terminal) and run:
```
git clone https://github.com/teh_popsicle/CareerSphere.git
cd CareerSphere
```
#### 3. Configure Environment Variables (.env)
- Locate the file: /App/.env
- Open it in a text editor.
- Add the required configuration values (such as API keys).
- Some API keys have already been added for demonstration purposes only.
- Save the file.

### Part 2: Running the Application
1. Start the Server
From the project root directory run the following command:
python run.py
2. Open in Browser
Open a browser and go to:
http://localhost:8000

### Part 3: Using CareerSphere
1. Start: Click Get Started on the homepage.
2. Dashboard: You will be taken to the dashboard.
3. Select a Tool: Choose any available tool based on your needs.
4. Follow On-Screen Steps:
  - Each tool provides guided instructions.
  - Enter requested information.
  - Review the results.
